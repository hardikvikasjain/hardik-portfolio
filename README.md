## 📖 Overview

This repository contains the source code for my personal developer portfolio. Moving deliberately away from bloated modern web frameworks, this workspace is built entirely upon a robust foundation of **Vanilla JavaScript, modern CSS3, and semantic HTML5**. 

The core architectural focus remains on maximum performance, deterministic browser behavior, and absolute zero-dependency execution. It serves as a central execution hub for my primary technical implementations in **Information Security, Systems Architecture, and Software Engineering.**

---

## 🛠️ Core Architecture & UI Mechanics

The infrastructure is designed to mirror the resource efficiency found in low-level systems programming, utilizing advanced CSS Grid and Flexbox paradigms. 

### 🔮 Interactive Components
* **Global Command Palette (`Ctrl + K`):** A fully functional keyboard-driven interface allowing instant navigation across sections, bypassing traditional scroll mechanics to mimic IDE workflows.
* **Draggable Terminal Environment:** A movable command-line interface utilizing native mouse-event tracking, featuring a cyberpunk aesthetic.
* **Live System Telemetry HUD:** A persistent monitor continuously displaying simulated network routing data and live session uptime.
* **Cryptographic Text-Reveal:** Intersection Observers trigger dynamic, randomized hexadecimal scrambling effects upon viewport entry.
* **Premium Glassmorphism & Cyberpunk Physics:** Custom scrollbars, neon-glow hover states, and CRT scanline overlays.
